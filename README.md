Dev-Folio - Personal Portfolio Website

📌 Project Overview

Dev-Folio is a responsive personal portfolio website developed as a Minor Project for Full Stack Web Development. It showcases my introduction, technical skills, and contact information.

🎯 Project Objectives

- Create a professional personal portfolio website.
- Design a responsive layout for mobile and desktop devices.
- Display technical skills using Bootstrap cards.
- Implement JavaScript-based contact form validation.
- Learn Git and GitHub for version control.

🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Git and GitHub

✨ Features

- Responsive navigation bar
- Personal introduction section
- Technical skills section
- Contact form with input validation
- Error messages for invalid inputs
- Success message after valid form submission
- Responsive design for different screen sizes

📂 Project Structure

dev-folio-project/
├── index.html
├── style.css
├── script.js
└── README.md

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open "index.html".
5. Right-click and select Open with Live Server.

📝 Contact Form Validation

- Name must not be empty.
- Email must have a valid format.
- Message must contain at least 10 characters.

Note: The contact form demonstrates client-side validation only. It does not send emails or store submitted messages.
